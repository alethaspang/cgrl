# cgrl
Github repository for data and code associated with Dr. Luis F. Alvarez Leon's Critical Geospatial Research Lab at Dartmouth College

Welcome! The following files are the R Notebooks used for running analysis of property sales and real estate data for the paper When COVID-19 Brought Tech to Miami:
Pandemic Exit, Regulatory Arbitrage, and the Birth of a Tech Hub (Spang, Alvarez Leon & Jha 2026).
